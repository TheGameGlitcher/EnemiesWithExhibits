## Enemies With Exhibits
This mod adds a JadeBox which allows enemies to simulate exhibits.
Exhibits relating to giving mana, cards, money, power, or gap options cannot be simulated fully. However, perhaps one day I will allow enemies to use power and mana.
Currently, the focus of the mod is a 1:1 port of the exhibits for the time being. In the future, I may look at tweaking the values if some exhibits are deemed too broken.

Exhibit Modifications:
- Rarity is ignored (for now).
- Anything relating to playing cards or spending mana still uses the Player's actions.
- Any "At the start of the Player's first turn" exhibits now become "At the start of combat" since enemies take their turn after the Player.
- Any exhibit that gives mana while also having a valid secondary effect now only has said secondary effect. This includes shining exhibits.
